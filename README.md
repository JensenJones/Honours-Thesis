# Honours Thesis

## Build

```sh
latexmk          # builds build/main.pdf (pdflatex + biber, reruns as needed)
latexmk -pvc     # rebuilds on every save
latexmk -c       # clears build files
```

In jvim, click **[Run]** in the status bar (or Cmd+Shift+A > "Run selected configuration").
**[Config]** picks between the entries in `.jvim/run.json`.

Code highlighting uses minted. TeX Live 2025's helper crashes on Python 3.14, so on a new
machine install a working copy once: `uv tool install --python 3.12 "latexminted==0.5.0"`.

Code blocks: `\begin{code}{toml}` ... `\end{code}` (any Pygments language name: `cpp`, `python`, ...),
inline `\mintinline{cpp}{std::visit}`.

## Layout

- `main.tex`: preamble, title details (`\thesistitle` etc.), chapter order
- `chapters/`: one file per chapter
- `figures/`: images, referenced by name without extension
- `references.bib`: generated by Zotero, do not edit by hand

Mark unfinished bits with `\todo{...}`; it renders in red.

## Zotero

Citations use biblatex (APA style) and keys from the Better BibTeX plugin.

One-off setup (DONE):

1. Install Better BibTeX: download the latest `.xpi` from
   https://github.com/retorquere/zotero-better-bibtex/releases, then in Zotero
   go to Tools > Plugins, click the gear icon, choose "Install Plugin From File", and restart Zotero.
2. Right-click the collection holding thesis references (or My Library) > Export Collection.
   Format: **Better BibLaTeX**, tick **Keep updated**, save over `thesis/references.bib`.

After that, anything added to the collection appears in `references.bib` automatically.
Copy an item's key with right-click > Better BibTeX > Copy Citation Key, then cite it with
`\parencite{key}` for (Author, Year) or `\textcite{key}` for Author (Year).
